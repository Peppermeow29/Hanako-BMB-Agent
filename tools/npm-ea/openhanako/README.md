# openhanako

Companion distribution name for **HanaAgent** — a personal AI agent
with memory and soul.

This is an **early-access** build published ahead of the 1.0 launch.
It installs an `openhanako` command that reports its version and the
release plan. From the 1.0 release this package aliases the primary
[`hanaagent`](https://www.npmjs.com/package/hanaagent) package and
forwards its CLI; until then both names carry the same early-access
build:

```
npm install -g hanaagent
```
